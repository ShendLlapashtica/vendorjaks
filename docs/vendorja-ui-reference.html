Give your builder this page and the four posters. Every size here is measured from your posters and written in cqw (percent of the screen's width), so the cropping and overlap look the same on every phone. The builder should rebuild these eight screens exactly, not interpret them.

Build rules. Copy these exactly.

Colors: exactly four, never changed

Red#FF0000 · every poster screen
White#FFFFFF · stack, collision, logo
Black#000000 · stagger, camera, buttons
Green#00A651 · "vendore" status only

Never

  • No dark mode and no theme switching. The red is #FF0000 everywhere: never darkened, never semi-transparent, never under an overlay, shadow, gradient, blur or filter. A darkened or overlaid red is what turns the screen brown.
  • No rounded cards, soft shadows, emoji or icons next to headlines. The type is the design.
  • Poster text is never centered and never fully visible. Only the vendorja logo is centered and whole.
  • Inside a screen, sizes use cqw on the screen container, not px or rem, so the crop is the same on every phone.
  • Use only these three text treatments. Don't invent a fourth.
